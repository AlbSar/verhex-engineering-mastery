# Daily Logs

Bu klasör günlük çalışma kanıtlarını tarih bazında tutar.

## Dosya düzeni

```text
04-daily-logs/
└── YYYY-MM/
    └── YYYY-MM-DD.md
```

Yeni günlük kayıt `templates/DAILY_LOG_TEMPLATE.md` dosyasından oluşturulur.

## Kural

Günlük log bir faaliyet listesi değildir. Şu dört öğeyi mutlaka içermelidir:

1. Çalıştırmadan önceki tahmin
2. Gözlemlenen gerçek sonuç
3. Yanlış zihinsel model veya öğrenilen mekanizma
4. Kod, test, terminal çıktısı ya da commit kanıtı

Kanıtsız “öğrendim” ifadesi ilerleme kaydı sayılmaz.
