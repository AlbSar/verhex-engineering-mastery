# Assessments

Bu klasör faz, ay ve bağımsız yeterlilik değerlendirmelerini tutar.

## Değerlendirme türleri

- Baseline assessment
- Haftalık assessment
- Faz sonu assessment
- Aylık teknik İngilizce assessment
- Capstone readiness review

## Değerlendirme ilkeleri

- Puan kanıta dayanır.
- İlk deneme ile AI destekli düzeltme birbirinden ayrılır.
- Kodun çalışması tek başına yeterli değildir.
- Açıklama, test, debugging ve production değerlendirmesi birlikte ölçülür.
- Düşük başlangıç puanı cezalandırılmaz; kanıtsız puan kabul edilmez.
